# Great Neck Navigator

Great Neck Navigator is its own hyperlocal community, professional-directory, membership, and local-opportunity product.

## Deployment
Upload the exact qualified Great Neck deployment ZIP to the repository root. Render verifies its SHA-256, safely unpacks it, runs the Great Neck release gate, and starts the extracted Great Neck deployment root.

Current coordination layer: **SMARTER Core Coordination Center (SCCC)**, formerly SMARTER Digital Growth Office / DGO. Historical DGO/UEC evidence is preserved. The **SMARTER Revenue Engine** is a separate shared acquisition/revenue/retention capability system.

The Great Neck Navigator Profile Factory remains a separate upstream profile-intelligence builder.
